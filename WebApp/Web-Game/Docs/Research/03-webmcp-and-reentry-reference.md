# WebMCP and Re-entry Reference

**Role:** Supporting mechanism reference

## Outer contract

The outer Re-entry Core defines a user-authorized future continuation: an authoritative event is
accepted by the Receiver, delivery is bounded, private context is activated through an adapter, the
Agent returns to the canonical page, the page exposes fresh tools, and the Agent stops at a human
boundary.

The game specializes the final application obligation. Its backend owns game truth. Its page exposes
current, permission-checked operations. A WebMCP tool is not a replacement for backend validation,
consent, persistence, or event delivery.

## Game-specific leverage

The game produces natural causal events and visible state: a soldier returns, dies, loses cargo,
encounters an enemy, a shelter is attacked, migration completes, or a shelter breaches. The Agent can
use a current dashboard to inspect those facts and choose a bounded next step.
