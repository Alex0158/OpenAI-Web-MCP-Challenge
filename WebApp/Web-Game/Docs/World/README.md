# World

This module owns the setting and world rules that remain true regardless of a particular UI or
implementation. It separates the magical fiction from the mechanics that implement it.

- [`00-world-overview.md`](00-world-overview.md) — persistent frontier, map, time, resources, and
  shelters;
- [`01-magic-and-lore.md`](01-magic-and-lore.md) — shelter magic, invisibility, protection, and
  corruption; and
- [`02-world-generation-and-zones.md`](02-world-generation-and-zones.md) — resource, monster, and
  terrain generation targets.
