# Blueprint

This module owns the product-level game concept. It answers what the world is, why it exists, what
problem it addresses, how the player wins, and where Re-entry Core and WebMCP are necessary. Detailed
rules stay in `World/`, `Mechanics/`, `Characters/`, `Design/`, and `Engineering/`.

- [`00-game-blueprint.md`](00-game-blueprint.md) — current concept and game boundary;
- [`01-raw-discussion-reference.md`](01-raw-discussion-reference.md) — owner wording preserved for
  fidelity; and
- [`02-core-concept-and-competition-thesis.md`](02-core-concept-and-competition-thesis.md) — the
  challenge-facing problem, advantage, mechanism, and desired outcome.
