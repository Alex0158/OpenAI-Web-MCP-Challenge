# Visual Reference Files

This directory is reserved for curated visual references used by the Sleepless Kingdom art lane.
The register in [`../07-reference-board.md`](../07-reference-board.md) is the source of meaning and
approval status.

Use these subdirectories when the first files are approved:

```text
references/
├── approved/    # owner-approved references used by the current visual direction
└── candidates/  # exploratory or superseded references retained for traceability
```

Reference images are not runtime assets. Runtime sprites and icons belong under the future
`public/assets/game/` path and require an asset-inventory entry and export contract.
