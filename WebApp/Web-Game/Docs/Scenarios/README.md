# Scenarios

Scenarios are supporting, concrete exercises of the canonical world and mechanism rules. They are
useful for design reviews, combat calibration, and future verification; they do not create new rules.

Reusable ordering lives in [`../Mechanics/Chains/README.md`](../Mechanics/Chains/README.md); each
scenario links to the chain it illustrates.

- [`01-first-session.md`](01-first-session.md) — starter shelter and first mission;
- [`02-gathering-encounter.md`](02-gathering-encounter.md) — route, cargo, detection, battle, and
  respawn;
- [`03-attack-and-migration.md`](03-attack-and-migration.md) — intelligence, siege, and veil;
- [`04-shelter-breach.md`](04-shelter-breach.md) — breach and soldier corruption; and
- [`05-reentry-agent-loop.md`](05-reentry-agent-loop.md) — backend event to bounded Agent continuation;
- [`06-cp06-clock-recovery-fixtures.md`](06-cp06-clock-recovery-fixtures.md) — clock, same-time order,
  restart, and bounded recovery vectors; and
- [`07-cp07-deterministic-world-fixture.md`](07-cp07-deterministic-world-fixture.md) — seed, placement,
  identity, reset, and route invariants.
- [08-cp08-projection-pathfinding-fixtures.md](08-cp08-projection-pathfinding-fixtures.md) — movement,
  scoped projection, fog, route invalidation, packet loss, reconnect, and unsupported realtime vectors;
  and
- [09-cp09-mission-role-return-fixtures.md](09-cp09-mission-role-return-fixtures.md) — dispatch, role
  lock, recall, return, stale context, death/reissue, and mission identity vectors.
- [10-cp10-economy-fixtures.md](10-cp10-economy-fixtures.md) — authoritative Wood/Rock extraction, cargo capacity, depletion, deposit, settlement, and retry vectors;
- [11-cp11-combat-fixtures.md](11-cp11-combat-fixtures.md) — monster contact, deterministic combat, cargo loss, respawn, and reissue vectors;
- [12-cp12-canvas-dashboard-fixtures.md](12-cp12-canvas-dashboard-fixtures.md) — Canvas projection, dashboard readability, discrete authoritative movement, fog, stale/reconnecting, and unsupported capability vectors;
- [13-cp13-webmcp-fixtures.md](13-cp13-webmcp-fixtures.md) — page-bound registration, permission, reread, bounded recall, and unsupported capability vectors;
- [14-cp14-reentry-adapter-fixtures.md](14-cp14-reentry-adapter-fixtures.md) — eligible signal, coalescing, cooldown, retry identity, active Thread, and external handoff vectors;
- [15-cp15-contract-race-verification-fixtures.md](15-cp15-contract-race-verification-fixtures.md) — contract, race, replay, restart, network, capability, and evidence checks;
- [16-cp16-local-vertical-slice-fixtures.md](16-cp16-local-vertical-slice-fixtures.md) — clean-reset two-player local G2 story and causal evidence vectors;
- [17-cp17-hosted-continuity-fixtures.md](17-cp17-hosted-continuity-fixtures.md) — host smoke, same-world binding, durable restart, health, realtime, and rollback vectors;
- [18-cp18-judge-reproduction-fixtures.md](18-cp18-judge-reproduction-fixtures.md) — clean-identity reviewer journey, independent readback, recovery, artifact integrity, and claim-boundary vectors.
