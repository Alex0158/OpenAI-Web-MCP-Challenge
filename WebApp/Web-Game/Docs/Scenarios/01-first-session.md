# Scenario: First Session

**Status:** Target scenario

**Logic chains:** [`../Mechanics/Chains/01-exploration-to-intelligence.md`](../Mechanics/Chains/01-exploration-to-intelligence.md),
[`../Mechanics/Chains/02-dispatch-to-deposit.md`](../Mechanics/Chains/02-dispatch-to-deposit.md)

1. Two players enter the same seeded 128 × 128 map. Their starter shelters have five soldiers each,
   protected start zones, and a separation of at least 80 logical tiles.
2. Each shelter senses Wood and Rock within its 24-tile resource field, while the player's 4-tile
   exploration reveal keeps the rest of the map fogged. Nearby exploration reveals
   one Wood node, one Rock node, and a monster patrol without forcing an immediate PvP encounter.
3. Player A assigns one gatherer with a tier-one tool to a Wood or Rock node, Player B remains visible
   as a separate world participant, and each player keeps the remaining soldiers at the shelter.
4. Each mission records its role, target, route, capacity, and return policy.
5. The player closes the page; the server continues world time and scheduled work.
6. The dashboard later shows current missions, cargo, estimated returns, and any causal events.
