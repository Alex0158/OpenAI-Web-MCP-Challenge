# Scenario: Attack and Migration

**Status:** Target scenario

**Logic chains:** [`../Mechanics/Chains/05-siege-to-breach.md`](../Mechanics/Chains/05-siege-to-breach.md),
[`../Mechanics/Chains/06-migration-to-relocation.md`](../Mechanics/Chains/06-migration-to-relocation.md)

1. The player explores the fogged map and discovers an enemy shelter.
2. The discovery returns as a time-stamped intelligence record after the player reaches home.
3. The player forms a siege party with one target coordinate and one route.
4. The enemy receives an attack event before assault contact and starts a paid migration.
5. The shelter consumes a veil charge, fades from fresh detection, stops its turret, and begins moving
   to a valid destination.
6. The siege party arrives at the old last-known position. It either finds no shelter or follows the
   later accepted search rule; it cannot receive the hidden current location automatically.
7. Existing enemy field soldiers continue their missions and return to the moving home anchor.
