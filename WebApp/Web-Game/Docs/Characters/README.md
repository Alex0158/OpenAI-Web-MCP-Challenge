# Characters and Actors

This module defines who can act in the world and which state belongs to each actor. Numeric balance
belongs to `Mechanics/` and art presentation belongs to `Design/`.

- [`01-player-and-shelter.md`](01-player-and-shelter.md) — player identity, shelter, and command
  authority;
- [`02-soldiers-and-roles.md`](02-soldiers-and-roles.md) — soldier identity, role loadouts, and
  lifecycle;
- [`03-monsters.md`](03-monsters.md) — generated and corrupted monsters; and
- [`04-other-players-and-world-actors.md`](04-other-players-and-world-actors.md) — other players,
  intelligence, and shared-world relationships.
