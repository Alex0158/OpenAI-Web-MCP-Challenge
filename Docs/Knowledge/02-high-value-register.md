## Register maintenance rule

When an item changes, update the owning source first, then this register, then the relevant
cross-layer reconciliation entry. If the evidence is only local, say so. If a statement is
volatile, retain its capture date and refresh path. If an item is rejected, preserve the
failure and demote it rather than deleting its history.
